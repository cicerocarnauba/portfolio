Medições de Obras

Aplicação Mobile & API REST · Gestão de Engenharia

Aplicativo mobile para engenheiros e fiscais registrarem medições físicas e financeiras direto no canteiro, substituindo cadernos e planilhas manuais. Opera com persistência local no aparelho e sincronização automática com a API quando há conexão, além de fotos com geolocalização, importação/exportação Excel e autenticação JWT.

Minha atuação: Desenvolvimento full stack, arquitetura offline-first, QA e gestão do projeto — telas em React Native, rotas e banco no back-end, testes unitários e segurança.
